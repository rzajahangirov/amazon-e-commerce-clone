# 📦 Amazon Clone — Backend Service

This directory contains the Spring Boot REST API service for the Amazon Clone platform.

> 📖 **Full Project Documentation:** For complete project architecture, API documentation, environment variables, and fullstack setup instructions, see the [Root README](../README.md).  
> 🛡️ **Senior Engineering Standards:** All contributions must strictly comply with the [Senior Developer Guidelines](SENIOR_DEVELOPER_GUIDELINES.md).

## 🚀 Quick Commands

```bash
# Compile and verify code
./mvnw clean compile

# Run tests
./mvnw test

# Start the Spring Boot backend
./mvnw spring-boot:run
```

- **API Base:** `http://localhost:8080`
- **Swagger Documentation:** `http://localhost:8080/swagger-ui.html`
