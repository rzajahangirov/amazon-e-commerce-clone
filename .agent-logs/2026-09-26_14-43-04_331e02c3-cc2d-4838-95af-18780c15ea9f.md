Göstərilən loqlarda Spring Boot Actuator xidmətinin sağlamlıq yoxlaması (Health Check) zamanı ortaya çıxan **iki fərqli xəta** var:

### 1. E-poçt Qoşulma Xətası (`AuthenticationFailedException`)

* **Mənası:** Tətbiq e-poçt (SMTP) serverinə qoşulmağa çalışır, lakin autentifikasiya üçün **şifrə tapmır** (`no password specified`).
* **Həlli:** `application.properties` (və ya `application.yml`) faylınızda e-poçt konfiqurasiyasını tamamlayın:
```properties
spring.mail.host=smtp.gmail.com
spring.mail.port=587
spring.mail.username=sizinemail@gmail.com
spring.mail.password=YOUR_APP_PASSWORD_HERE

```


* *Mail istifadə etmirsinizsə*, bu yoxlamanı söndürə bilərsiniz:
```properties
management.health.mail.enabled=false

```



---

### 2. Redis Qoşulma Xətası (`RedisConnectionFailureException`)

* **Mənası:** Tətbiq `localhost:6379` ünvanındakı Redis serverinə qoşula bilmir, bağlantı rədd edilir (`Connection refused`).
* **Həlli:**
1. Redis serverinin komputerdə aktiv (işlək) vəziyyətdə olduğundan əmin olun (məsələn, `redis-server` əmri və ya Docker konteyneri ilə başladın).
2. Redis fərqli ünvan və ya portdadırsa, konfiqurasiyanı yeniləyin:
```properties
spring.data.redis.host=localhost
spring.data.redis.port=6379

```




* *Redis yoxlamasını söndürmək üçün:*
```properties
management.health.redis.enabled=false

```
