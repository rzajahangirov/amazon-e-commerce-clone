Mən artıq bu problemi aradan qaldırdım. Layihə problemsiz build olundu. Problemin niyə yarandığını və silinmənin sistemə təsirlərini detallı izah edim:

### Xətanın Səbəbi Nə İdi?
Sizin `Invoice.java` (Qaimə) modelinizdə məlumatların eyni anda iki nəfər tərəfindən dəyişdirilməsinin qarşısını almaq üçün `@Version` annotasiyası istifadə olunub. Eyni zamanda qaimələrin fiziki silinməsinin qarşısını almaq üçün isə `@SQLDelete` (Soft Delete) sorğusunu özünüz manual yazmısınız:
`UPDATE invoices SET is_deleted = true WHERE id=?`

Hibernate silmə komandasını verəndə, `@Version` olduğuna görə avtomatik arxa planda SQL-ə **2 parametr** ötürməyə çalışır: həm qaimənin **id**-sini, həm də **version**-unu. Lakin sizin yazdığınız yuxarıdakı SQL sorğusunda sadəcə **1 ədəd** `?` işarəsi var idi (yalnız `id=?`). Ona görə də Hibernate 2-ci parametri qoşmağa yer tapmır və bu səbəbdən _"column index out of range"_ xətasını atırdı.

Mən sadəcə həmin sətri bu cür dəyişdirdim:
`@SQLDelete(sql = "UPDATE invoices SET is_deleted = true WHERE id=? and version=?")`
Beləliklə sistem hər iki parametri uğurla ötürə bilir.
